이 파일은 서버가 필요합니다

dev.html 은 ES 모듈로 나뉘어 있어 file:// 로 직접 열면 브라우저가 CORS 정책으로 막습니다.

같은 폴더의 index.html 을 더블클릭하세요. 그 파일은 서버 없이 바로 열립니다.

개발용으로 이 파일을 쓰려면 폴더에서 python -m http.server 8123 을 실행하고 http://localhost:8123/dev.html 로 접속하세요.

레드스톤 규칙

  • 신호 세기는 0 ~ 15. 와이어를 한 칸 지날 때마다 1씩 줄어듭니다.
  • 레드스톤 블럭 · 레버 · 토치 · 리피터 출력은 세기 15의 전원입니다.
  • 일반 블럭은 충전될 수 있습니다. 비전도 블럭(유리)과 바닥판은 절대 충전되지 않습니다.
  • 토치는 자기가 붙은 블럭이 충전되면 꺼집니다.
  • 리피터는 신호를 15로 되살리고, 한쪽 방향으로만 흘려보내며, 지연을 1~4틱 줍니다.
